The Personal Task Manager is a simple mobile application built using the Flutter framework. The application allows users to manage daily tasks by adding, editing, completing, and deleting tasks. This project was developed without using any backend service or database, and all data is stored temporarily in memory during runtime, as required by the assignment.


Welcome Screen

View list of tasks

Add a new task with title and description

Edit existing tasks

Mark tasks as completed Delete tasks with confirmation dialog

Snackbar messages for user feedback
